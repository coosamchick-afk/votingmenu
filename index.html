Konfigurasi Koneksi Backend Google Apps Script

Saat di-deploy di Cloudflare Pages, aplikasi menggunakan URL ini untuk membaca & menyimpan data langsung ke Google Sheets Anda.
Tips Permanen untuk Cloudflare Pages:
Anda juga bisa menempelkan URL /exec langsung pada variabel DEFAULT_GAS_WEB_APP_URL di baris awal script index.html agar seluruh perangkat otomatis terhubung. Selain itu, setiap Link Khusus Polling yang Anda salin dari dashboard ini otomatis menyertakan koneksi ke database Anda.
